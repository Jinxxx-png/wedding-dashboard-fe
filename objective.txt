# PROJECT: WEDDING PROJECT FRONTEND

Act as a Senior React Frontend Engineer and UI/UX Designer.

Develop a premium, modern, production-ready frontend for a centralized Wedding Management Platform called Wedding Project.

This is a standalone React application.

IMPORTANT:
- Work only inside the current frontend directory.
- Do not create or modify the Golang backend.
- Do not put backend files inside this project.
- Do not implement a second database.
- Do not connect directly to Firebase Firestore.
- All protected data must be retrieved through the Golang REST API.
- The backend is responsible for authentication, authorization, tenant isolation, and business logic.

The backend and frontend are two completely separate applications.

# 2. APPLICATION CONFIGURATION

The backend API URL must be configurable through environment variables.

Create:

.env.example

VITE_API_BASE_URL=http://localhost:8080/api/v1

Never hardcode production API URLs.

Configure Axios to:
- Use the configured API base URL.
- Send credentials with requests.
- Handle HTTP errors consistently.
- Handle expired sessions.
- Handle unauthorized requests.
- Support file downloads.
- Avoid sending requests repeatedly after authentication expires.

Use secure HTTP-only cookie authentication.

Do not store passwords, session IDs, or authentication tokens in localStorage.
